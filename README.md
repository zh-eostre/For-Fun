# 晴川小镇

一个像素风的城镇经营小游戏。从一座市政厅开始，铺路、盖民居、建农场，熬过冬天，把拓荒地发展成「繁华之城」。

纯 HTML + CSS + 原生 JS，没有依赖、不需要构建。直接双击 `index.html` 就能玩（`file://` 也行），存档保存在浏览器的 localStorage 里。

## 文件结构

```
index.html        页面骨架，按顺序加载下面的脚本
css/style.css     全部样式（含深色模式、手机布局）
js/
  config.js       数值配置：建筑表 B、建造栏顺序、小镇等级、任务、交易
  state.js        全局状态 S / UI / SETUP，坐标与计数工具函数，存读档，日志
  map.js          地图生成（河谷 / 湖区 / 密林 / 山地），新存档初始状态
  setup.js        开局选地图界面
  sim.js          每日模拟：道路连通、工人分配、服务覆盖、产出、幸福度、
                  民居升降级、人口迁入迁出、季节、等级、任务、随机事件
  actions.js      放置 / 拆除 / 砍树凿石，工具选择
  sprites.js      所有像素画（地形、建筑精灵、四季调色板）和图标生成
  render.js       画布绘制：静态层缓存、行人、炊烟、气泡、放置预览
  ui.js           DOM 界面：顶栏、建造栏、侧栏、详情面板、标题页、弹窗、提示
  main.js         点击动作表 ACT、键盘快捷键、主循环、启动
pixel-town.html   拆分前的原始单文件版本（留作对照，可删除）
```

这些脚本是普通的 `<script>`，不是 ES module，顶层的 `const` / `let` / `function` 共用同一个全局作用域。所以**加载顺序很重要**：`config.js` 必须最先，`main.js` 必须最后（它会立即启动游戏）。新加文件时，记得把它放进 `index.html` 里合适的位置。

## 核心循环

- **时间**：每季 7 天，一年 28 天。1 倍速下一天 2.6 秒，可调暂停 / 1× / 2× / 4×（空格键暂停）。
- **连通**：从市政厅出发，用 BFS 找出所有连通的道路和桥。建筑只要紧挨着连通的道路（或市政厅）就算「已连通」，没连通的建筑不运作。
- **工人**：总人口就是劳动力，按 农场 → 渔屋 → 伐木场 → 采石场 → 市场 → 学校 → 神庙 → 工坊 的优先级分配，同类建筑先建的先分到人。缺人时产量按比例下降，可以手动「停工」把人让出来。
- **消耗**：每人每天吃 0.25 粮食；冬天每栋有人住的民居还要烧木材取暖。

## 民居

| 等级 | 名称 | 容量 | 每人每天税 | 冬天取暖木材/天 |
|---|---|---|---|---|
| 1 | 木屋 | 4 | 0.2 | 0.3 |
| 2 | 砖房 | 8 | 0.35 | 0.45 |
| 3 | 宅院 | 14 | 0.55 | 0.6 |

- **木屋 → 砖房**：连路 + 水井 + 市场 + 幸福度 ≥ 50 + 住满 75%
- **砖房 → 宅院**：再加学校 +（公园或神庙）+ 幸福度 ≥ 65
- 条件连续满足 2 天才会升级。维持条件（砖房：路、水、市场、幸福度 ≥ 40；宅院再加学校、公园或神庙、幸福度 ≥ 55）连续 4 天不满足就退化一级。
- 税率：低 ×0.6（幸福度 +8）、中 ×1、高 ×1.5（幸福度 −12）。

## 幸福度与人口

目标幸福度 = 基础 50 + 粮食（充足 +10 / 短缺 −25）+ 冬天缺柴 −20 + 税率 + 公共服务 + 钟楼 +10 + 庙会 +15，限制在 0–100。实际幸福度每天向目标靠近 30%。

公共服务分按人口加权平均：每位居民的分数 = 水井 4 + 市场 4 + 公园 8 + 神庙 12（只算覆盖到他家的服务）。

- **迁入**：幸福度 ≥ 35 且不缺粮时，每天最多迁入 max(2, 人口 × 8%) 人，每栋每天最多 +2。
- **迁出**：幸福度 < 25，或连续缺粮 ≥ 2 天时，每天迁出 max(1, 人口 × 6%) 人。
- 没连路的民居每天走掉 1 人。

## 随机事件

第 12 天第一次触发，之后每 9–15 天一次，从当前可用的事件里随机抽：

- 🐫 旅行商人：从 `TRADES` 里随机给 2 个交易
- 💰 捡到金币：+20–40
- 🌾 大丰收（夏、秋）：农场产量翻倍 3 天
- 🌨️ 暴风雪（冬）：取暖木材翻倍 3 天
- 🧳 移民（人口 ≥ 6 且空位 ≥ 4）：最多迁入 6 人
- 🏮 庙会（人口 ≥ 15）：花 💰40，5 天幸福度 +15

## 地图

大小有 小 24×16 / 中 34×22 / 大 46×30 三种。地形有四种：

- **河谷**：一条河加平原，最均衡
- **湖区**：多湖，石头少
- **密林**：树多，要先清出空地
- **山地**：岩石多，缺水缺粮

市政厅固定在地图中央，周围会清出一圈空地。

## 存档

localStorage 键名 `qingchuan-town-v1`，内容就是整个状态对象 `S`（带版本号 `v: 1`）。如果改了状态结构，记得一起提升版本号或者写迁移，否则旧存档会读不出来。
