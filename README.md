# For-Fun

Small projects made for fun. Each project lives on its own branch.

| Project | Branch | What it is |
|---|---|---|
| 绿茵经理 | [`football-manager`](../../tree/football-manager) | Browser football manager: two divisions with promotion, cup, calendar and training, academy, transfers and loans. Open `football-manager.html` to play. |
| 深渊之塔 | [`abyss-tower`](../../tree/abyss-tower) | Card-battler roguelike: climb a 13-floor tower with a deck of cards, relics, elites, shops and events, and a boss at the top. Open `abyss-tower.html` to play. |

To work on a project:

```
git clone -b <branch> https://github.com/zh-eostre/For-Fun.git
```
